プライバシーポリシー

制定日：2026年9月27日　／　English

文明の設計図 Studio（Bunmei Studio Uploader、以下「本ツール」）は、YouTube チャンネル「文明の設計図」（@bunmei-sekkeizu）の運営者が、自分で制作した動画を自分のチャンネルに投稿するための個人用ツールです。本ツールを使うのは運営者本人だけです。

YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールを利用する人は、YouTube 利用規約に同意したものとします。Google による情報の取り扱いについては、Google プライバシーポリシーをご覧ください。

アクセスする情報

本ツールは、OAuth 2.0 で運営者の Google アカウントにログインし、運営者が許可した範囲で次の情報にアクセスします。

  • チャンネルの ID と名前（正しいチャンネルにログインしているかの確認のため）
  • チャンネル自身の再生リストの一覧（動画を再生リストに追加するため）
  • 本ツールがアップロードした動画の ID と処理状態

情報の使い方

上の情報は、動画のアップロード、サムネイルの設定、再生リストへの追加のためだけに使います。広告、分析、プロファイリングには使いません。

保存と共有

  • ログインのためのトークンは、運営者のパソコンの中にだけ保存します。外部のサーバーには送りません
  • アップロードした動画の ID と URL は、運営者の制作記録として保存します
  • 情報を第三者に提供したり、販売したりすることはありません

アクセスの取り消しと削除

本ツールへのアクセスの許可は、いつでもGoogle アカウントの「サードパーティ製のアプリとサービス」から取り消せます。取り消すと、本ツールは YouTube の情報にアクセスできなくなります。パソコンに保存したトークンは、取り消しと同時に削除します。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と、他のアプリへの転送は、限定使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに準拠します。

このサイトについて

このサイトは Cookie や解析ツールを使っていません。サイトは GitHub Pages で公開しています。

変更

Privacy Policy

Effective date: September 27, 2026

Bunmei Studio Uploader (“the tool”) is a private tool used only by the owner of the YouTube channel “文明の設計図 / Blueprints of Civilization” (@bunmei-sekkeizu) to upload videos the owner produces to that channel. The channel owner is the only user of the tool.

Use of YouTube API Services

The tool uses YouTube API Services. By using the tool, users agree to be bound by the YouTube Terms of Service. For how Google handles information, see the Google Privacy Policy.

Information the tool accesses

The tool signs in to the owner's Google account with OAuth 2.0 and, within the permissions the owner grants, accesses:

  • The channel ID and name (to confirm it is signed in to the correct channel)
  • The list of the channel's own playlists (to add videos to them)
  • The IDs and processing status of the videos the tool uploads

How the information is used

This information is used only to upload videos, set their thumbnails, and add them to the channel's playlists. It is not used for advertising, analytics, or profiling.

Storage and sharing

  • Sign-in tokens are stored only on the owner's computer and are never sent to any other server
  • The IDs and URLs of uploaded videos are kept as the owner's production records
  • No information is shared with or sold to third parties

Revoking access and deletion

Access can be revoked at any time from the third-party apps & services page of your Google Account. After revocation the tool can no longer access YouTube data, and the tokens stored on the computer are deleted.

Google API Services User Data Policy

Bunmei Studio Uploader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

About this site

This site does not use cookies or analytics. It is hosted on GitHub Pages.
