文明の設計図 Studio
BLUEPRINTS OF CIVILIZATION STUDIO

このツールについて

文明の設計図 Studio（Bunmei Studio Uploader）は、YouTube チャンネル「文明の設計図」（@bunmei-sekkeizu）の運営者が、自分で制作した動画を自分のチャンネルに投稿するための、個人用のツールです。世界遺産が建てられていく様子を 3DCG で再現した動画を、制作の最後に自動で予約投稿します。

できること

  • 完成した動画を、非公開のまま予約公開の日時をつけてアップロードする
  • その動画のために作ったサムネイルを設定する
  • チャンネル自身の再生リストに、その動画を追加する

使う人

チャンネルの運営者本人だけです。運営者のパソコンの上だけで動き、ほかの人には提供していません。ほかのユーザーのデータにはアクセスしません。

このツールは YouTube API サービスを利用しています。扱う情報についてはプライバシーポリシーをご覧ください。

About this tool

Bunmei Studio Uploader is a private tool used only by the owner of the YouTube channel “文明の設計図 / Blueprints of Civilization” (@bunmei-sekkeizu) to upload the videos the owner produces — 3DCG reconstructions of how world heritage sites were built — to that channel.

What it does

  • Uploads a finished video as private, with a scheduled publish time
  • Sets the custom thumbnail made for that video
  • Adds the video to the channel's own playlists

Who uses it

Only the channel owner. It runs on the owner's own computer and is not offered to anyone else. It does not access any other user's data.

This tool uses YouTube API Services. See the Privacy Policy for how information is handled.
